# Security policy

## Supported versions

Only the latest release of Tango receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting on the Security tab of <https://github.com/Omi773/Tango>, or contact the maintainer through <https://github.com/Omi773>.

Include what you found, how to reproduce it and the Tango version. You will get a reply as soon as the maintainer can, and credit in the fix if you want it.

## Scope

Tango stores Discord tokens in the iOS Keychain and plays files you choose. Issues involving token storage, network storage credentials or handling of untrusted audio files are in scope.
