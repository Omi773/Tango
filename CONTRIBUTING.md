# Contributing to Tango

Thanks for helping. Bug reports, ideas and pull requests are welcome.

## Reporting a problem

Open an issue at <https://github.com/Omi773/Tango/issues/new> with your iOS version, the Tango version (Settings → About), what you did and what happened. Do not include passwords or access tokens.

## Pull requests

1. Fork the repository and create a branch.
2. Run `flutter pub get`, `dart format .` and `flutter analyze` before you push.
3. Keep changes focused, and describe what changed and why.
4. For interface work, reuse the Rhythm kit in `lib/widgets/rhythm/` instead of adding one-off widgets.

## Translations

Strings live in `lib/l10n/arb/`. Add new keys to `app_en.arb` first.
